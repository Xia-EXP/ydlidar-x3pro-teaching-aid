YDLIDAR X3 PRO 雷达控制台 v0.1.3
Windows 便携版 · 2026-10-14

给其他电脑使用
1. 把整个 ZIP 压缩包复制到目标电脑。
2. 右键“全部解压”，放到可写的普通文件夹。支持中文和空格路径。
3. 双击“一键启动.cmd”（英文入口 one-click-start.cmd 功能相同）。
4. 等待环境检查结束，Microsoft Edge 会自动打开雷达控制台。
5. 保持启动窗口运行。在网页点击“选择串口”，选择实际雷达转接板，再点击“连接”。
6. 使用结束后，先在网页点击“断开”，再回到启动窗口按回车结束服务。

电脑要求
- Windows 10/11，64 位 Intel/AMD（x64）。本包不适用于 macOS 或 Linux。
- 已安装 Microsoft Edge；没有 Edge 时启动器会提示安装方式。
- 已正确安装 USB 转串口转接板驱动，雷达使用匹配的供电和接线。
- 内置 Node.js，无需另装 Node、npm、Python 或开发工具。
- Edge 和 USB 驱动已具备时，正常运行无需联网，也无需管理员权限。

常用操作
- “连接设置”：波特率与 DTR，默认 115200 / 8N1。
- “开始扫描 / 停止扫描”：按需请求雷达启停扫描；部分转接板需要 DTR 控制。
- 扫描图上的“扫描图层”和地图上的“地图设置”：展开相关设置；Escape 可收起。
- 扫描图默认按整圈刷新以避免闪烁；“当前扫描波束 / 当前包回波 / 已扫扇区”需在“扫描图层”中勾选，开启后波束会快速跳动。
- 点击扫描点或聚焦扫描图后按 Enter：查看角度、距离及 X/Y 坐标。
- 首屏右侧“G1 避障仿真”：宇树 G1 模型按雷达建议在 3D 场景中预演前进/转向/停止；拖动旋转、滚轮缩放，“复位视角”恢复机位，“放大”铺满窗口，Escape 退出。它只是可视化，不控制任何机器人。
- 下方“参数调整 / 数据诊断 / 教学说明 / 案例视频”：调整实验参数、查看原始包、阅读图例和播放课堂案例视频。
- “案例视频”：四段本地短片（G1 避障演示、G1 绕桩完整演示、缝隙跟随法、TF 与坐标），可切换、按章节跳转、慢放、标记；“剧场模式”铺满窗口，Escape 退出。
- 固定局部图用于静止雷达；移动后先清空。实验性增量建图不是完整 SLAM。
- 避障区仅显示几何建议，不会向机器人发送运动命令。

打不开时
- 必须先完整解压，不能在 ZIP 预览窗口中直接双击运行。
- 不要直接打开 public/index.html；应由“一键启动.cmd”启动本地服务。
- 允许启动窗口完成环境检查；服务会自动选用 5173–5193 中的空闲端口。
- 无雷达数据时依次检查：供电、USB 驱动、COM 口、115200 波特率和接线。
- 学校或单位策略禁止 PowerShell / 串口访问时，需要本单位管理员调整策略。

文件说明
- public：最新版控制台界面与雷达处理源码；public/media 为案例视频，public/models/g1 为宇树 G1 模型（含 BSD-3 许可证），public/vendor/three 为 three.js（MIT）。
- runtime：已核对官方 SHA-256 的 Node.js，以及官方许可证和来源记录。
- FILES.sha256：压缩包内各文件的完整性校验值。
- README.md、MODULES.md：详细使用说明与模块说明。
- RELEASE-NOTES.md：本版变更与验证范围。

升级时请把新版解压到新文件夹，再启动新版目录中的“一键启动.cmd”。
本包通过软件与模拟数据检查，实际雷达、驱动和转接板仍需在目标电脑连接验证。
