      视频本工具对应
      激光雷达持续扫描极坐标图青色扫描射线

      3上机复现 8 分钟

      1. 连接雷达，前方无遮挡，确认建议为“前进”。
      2. 在前方偏左约 0.6 m 放纸箱：建议是否变为“右转”？
      3. 一位同学站到正前方 0.4 m 内：是否变为“停止”？
      4. 同学走开：是否恢复“前进”？每次记下建议和触发规则。
      5. 把纸箱换成比雷达扫描面更矮的物体，再试一次。

      4讨论小结 3 分钟

      • 视频里遇箱子绕行、遇行人停步。本工具能分清箱子和人吗？为什么？
      • 矮物体为什么没被“看到”？单线雷达只扫描一个平面。
      • 动画中的“通路恢复”对应本工具收到新一圈扫描后重新判断。

      本工具只按几何距离给建议，不识别人或物体，也不控制电机。

      动画讲解的是绕桩路线，控制台的 G1 视图用于预演当前一条几何建议。

      1看前提问 2 分钟

      先打开“教学说明”回顾：本工具把前方、左侧、右侧分成三个固定扇区，只比较三个距离。

      • 如果前方有两张椅子，中间留一条缝，三扇区法会怎么判断？
      • 机器人想“钻缝”，除了缝在哪，还需要知道什么？

      2对照观看 2 遍 · 约 3 分钟

      第一遍完整看；第二遍用 0.5× 播放，在每一步出现时点“标记此刻”。

      1. 限距：太远或无效的读数截断，只关心近处。
      2. 找最近点：这是最危险的障碍。
      3. 安全气泡：把最近点周围车身半径内的读数清零。
      4. 最大缝隙：找连续最长的“非零”角度区间。
      5. 选目标方向：取缝隙中最远点或中心，转向它。

      以上是该方法的常见步骤，具体以视频讲解为准，可按视频修改标记。

      3上机对比 8 分钟

      1. 用两个纸箱在雷达前 0.6–1 m 处摆出一条缝，连接雷达。
      2. 在极坐标图里用肉眼找“最大缝隙”，读出它的角度范围。
      3. 点缝隙两侧的点，在“点位读数”中记下两端距离和角度，估算缝宽。
      4. 记下左侧栏“避障建议”。它与缝隙跟随会选同一个方向吗？
      5. 把缝收窄到比机器人还窄，再比较一次。

      4讨论小结 3 分钟

      三扇区法（本工具）缝隙跟随法
      看什么三个扇区的最近距离每个角度的连续可通行区间
      输出前进 / 左转 / 右转 / 停止一个具体的目标角度
      优点规则少，容易解释能发现窄缝，转向更平滑
      风险缝被扇区“平均”掉气泡太小会擦碰，缝隙会跳变

      本工具未实现缝隙跟随，以上对比由学生观察完成；工具仍不会控制电机。

      1看前提问 2 分钟

      • “点位读数”里的 X（前）、Y（左）是相对谁说的？
      • 箱子不动，只把雷达转个方向，箱子的 X/Y 会变吗？

      2对照观看 2 遍 · 约 3 分钟

      观察固定障碍在雷达、车身和地图坐标系里的位置，再对照本工具。

      视频中的坐标本工具对应
      雷达坐标极坐标图的距离、角度及 X/Y
      车身坐标“角度偏移”可用来演示安装朝向的换算
      出发点 / 地图实验性建图：以第一帧为起点估计位姿

      3上机复现 8 分钟

      1. 纸箱放雷达正前方约 1 m，点选它，记下角度、X、Y。
      2. 箱子不动，把雷达原地转约 90°，再点选：X/Y 变成多少？
      3. 调“参数调整 → 角度偏移”，直到箱子回到正前方，记下偏移值。这就是一次手动的坐标“翻译”。
      4. 打开“反转左右方向”，看 Y 的正负怎么变。
      5. 地图切到“实验性建图”并开始，缓慢平移雷达：箱子在地图中是否基本留在原处？

      4讨论小结 3 分钟

      • 为什么“东西没动，车身坐标却一直变”？要描述不动的东西该选哪个原点？
      • 本工具里一个点经历了哪几次“翻译”？（原始角度 → 三角修正 → 角度偏移 → X/Y）
      • 坐标变换能解决错误的测距读数吗？

      本工具没有 ROS TF 树，只用角度偏移和左右反转演示最简单的二维变换；建图位姿为实验性估计。
