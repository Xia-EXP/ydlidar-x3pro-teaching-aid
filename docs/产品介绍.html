YDLIDAR X3 PRO · v0.1.5 · 2026-11-24

产品介绍

YDLIDAR X3 PRO 雷达控制台是本地教学软件，供教师演示二维激光测距、坐标变换、局部占据栅格和几何避障，供学生在实物测量中观察每一圈扫描。

主要功能

  • 设备连接通过 Edge Web Serial 读取转接板串口。极坐标图和点位读数显示距离、角度与 X/Y。
  • 局部地图显示未知、空闲与占据区域。实验性增量建图使用相邻扫描估计相对位置，适用于演示匹配和漂移。
  • G1 避障仿真把扇区清距和前进、转向、停止建议显示在三维场景中。控制台只向雷达发送适用的扫描启停指令。
  • 案例视频收录 G1 避障、绕桩路径、缝隙跟随法和 TF 与坐标四段原创教学动画，每段 24 秒，附章节和课堂讨论。

使用环境

Windows 10/11 x64、可写目录、Microsoft Edge。程序附带 Node.js v24.19.0。驱动就绪后可离线运行，3D 视图需要 WebGL。无硬件可浏览教学说明和播放案例，有硬件时可使用实时测距、数据诊断与建图。

软件显示的数据来自课堂雷达或明确标注的示意场景。本版的软件验证和目标电脑实机联测状态见 GitHub 发行记录。
